# <AI 성공의 퍼즐조각> 상업용 앱 제작 마스터 프롬프트

아래 프롬프트를 코딩 에이전트 또는 앱 제작 AI에 그대로 제공하고, 원본 PDF `성공의 퍼즐조각 본문-3.pdf`도 함께 첨부한다.

---

## 역할과 최종 목표

당신은 상용 SaaS 제품을 실제로 설계·개발·검증하는 시니어 제품팀이다. 제품명은 **<AI 성공의 퍼즐조각>**이다.

첨부된 홍창준 저자의 책 **《비즈니스 성공의 퍼즐조각》** 전체를 원문 근거로 분석하고, 사용자가 자신의 현재 상태를 점검하여 강점·약점·위험요인·우선 행동을 발견하고 실제 행동을 누적할 수 있는 한국어 상업용 웹앱/PWA를 완성하라. 예쁜 시안이나 정적 목업에 그치지 말고 회원, 저장, 평가, 계획, 실행 기록, 리포트, 전자책, 관리자 운영, AI 연결 상태가 실제로 작동하는 제품을 만든다.

앱의 핵심 메시지는 다음과 같다.

> 실패와 거절도 버려지는 경험이 아니라 성공이라는 큰 그림을 완성하는 퍼즐조각이다. 성공은 자신의 행복에 부족한 조각을 찾고, 명확한 목표를 세우며, 실행·회복·학습·관계·끈기를 자기주도적으로 반복하는 과정이다.

## 책 분석에서 반드시 보존할 핵심 구조

책은 125개 PDF 면이며, 본문 PDF 면 다수는 인쇄면 두 쪽이 합쳐진 가로형 펼침이다. 목차에는 머리말과 85개의 짧은 주제 글이 있으며 인쇄면 기준 약 248쪽까지 이어진다. 앱은 책의 원문, 저자의 주장, 앱의 현대적 코칭 해석을 서로 구분해야 한다.

책 전체를 다음 12개의 “성공 퍼즐”로 구조화하되, 관리자가 장별 매핑과 가중치를 수정할 수 있게 한다.

1. **의미·행복·안정**: 돈만이 아닌 목표 달성, 현재와 미래의 균형, 건강·가족·경제적 안정, 후회 없는 삶과 남길 가치
2. **목표·계획·우선순위**: 분명한 동기, 구체적 목표, 큰 목표의 세분화, 버킷리스트 우선순위, 단기·장기 목표의 연결
3. **실행·결단·기회 포착**: 생각을 행동으로 옮김, 두드림, 즉시 실행, 순간 판단, 기회가 반복될 것이라는 착각 경계
4. **끈기·실패 회복·꾸준함**: 실패를 전제로 한 도전, 거절 내성, 작심삼년, 멈추지 않음, “끈기 있게 성공”하는 반복
5. **집중·시간·에너지 관리**: 초집중, 시간 선택, 효율적 휴식과 숙면, 에너지를 주고 빼앗는 환경, 메모 습관
6. **학습·정보·디지털 역량**: 책과 사람에게서 배우기, 지피지기, 벤치마킹, 지식 투자, 디지털 문해력, 자기 성찰
7. **재무·생산성·생존력**: 소비보다 생산, 저축과 현금흐름, 수입 구조, 한탕주의 경계, 현실 점검과 미래 대비
8. **비즈니스·영업·고객가치**: 영업력, 고객 이해, 진실한 제안, 작은 차별화, 단기 성과와 장기 관계, 평생 고객
9. **인맥·소통·선한 영향력**: 인맥 디자인, 질문과 대답, 주고 나눔, 에너지 관계, 사람을 넓고 깊게 이해하기
10. **리더십·조직·리쿠르팅**: 자기 리더십, 역할과 책임, 리더 간 존중, 조직 갈등, 준비된 자신을 보여주는 채용·협업
11. **자기효능·태도·독창성**: 확신, 긍정 언어, 한계 확장, 자존중, 비교 대상 선택, 고유한 색과 특별성
12. **자기주도·윤리·균형**: 남 탓 대신 성찰, 맹목적 추종이 아닌 검증된 멘토링, 건강·동의·공정성을 지키는 자발적 성공

책의 대표적인 원리를 앱의 기본 시드 데이터로 반영한다.

- 성공 4단계: `동기부여와 목표수립 → 실행 → 적절한 충전 → 인맥 디자인`
- 목표는 행동 가능한 작은 단계로 쪼갠다.
- 성공과 행복은 동일어가 아니며, 자신의 행복에서 부족한 조각이 무엇인지 먼저 찾는다.
- 현재의 행복과 미래의 준비를 함께 본다.
- 생산형 목표와 소비형 목표를 구분한다.
- 실패·거절·난관을 학습 기록으로 바꾸고 다음 시도를 설계한다.
- 시간, 집중, 꾸준함, 기록, 지식, 관계가 복리처럼 누적된다.
- 돈만 쫓기보다 사람에게 실제 가치를 제공하고 신뢰 관계를 만든다.
- 자기주도적 동기·계획·실행이 없는 성공은 지속되기 어렵다.
- 저자의 강한 표현이나 시대적 견해는 “책의 관점”으로만 표시하고 보편적 사실이나 과학적 진단으로 단정하지 않는다.

## 매우 중요한 안전·윤리·권리 원칙

원본 판권면에는 저자와 출판사에 권리가 있다고 명시되어 있다. PDF를 상업 서비스에서 열람·배포하기 전에 관리자가 디지털 전송권·전자책 서비스권 등 필요한 권리를 확보했다고 확인하는 **권리 승인 게이트**를 둔다. 승인 전에는 개발자와 권한 있는 관리자만 원문을 볼 수 있고 공개 사용자에게 PDF, 페이지 이미지, 다운로드 URL을 노출하지 않는다.

원문은 보존하되 진단과 AI 코칭에서는 다음 표현을 그대로 사용하지 않는다.

- “루저”, “바보”, “문맹”, “찌질하다” 등 사람을 낙인찍는 표현
- 외모·성별·연령·계층에 대한 고정관념
- 과로, 수면 부족, 극단적 몰입을 성공의 필수조건으로 미화하는 표현
- 상사의 지시나 멘토를 “무조건 따르라”는 식의 맹목적 복종
- 공격적 영업, 관계의 도구화, 사람을 돈의 수단으로 보는 해석
- 우울, 자살, 위기 상황을 의지 부족으로 환원하거나 수치심을 주는 표현

이런 내용은 원문 뷰어에서는 역사적 원문 그대로 읽을 수 있으나, 필요하면 “현대적 적용 시 건강·권리·동의·다양성을 함께 고려하세요”라는 맥락 안내를 표시한다. 사용자가 자해·자살 의도를 표현하면 성공 코칭을 중단하고 즉시 안전 확인과 해당 국가의 검증된 긴급 지원 안내 흐름으로 전환한다.

결과는 성격검사, 의학적 진단, 투자 자문, 성공 보장, 능력 판정이 아니다. “현재 응답에서 나타난 경향과 행동 증거”로 표현한다. 낮은 점수를 실패자 낙인으로 사용하지 않는다.

## 핵심 사용자 경험: 한 화면 안의 토탈 솔루션

전체 앱은 데스크톱에서 하나의 우아한 메인 프레임 안에서 동작하고, 메뉴를 누르면 URL 페이지 전환이나 전체 새로고침 없이 중앙 콘텐츠만 부드럽게 바뀌는 SPA로 만든다. 모바일에서는 같은 정보 구조를 하단 내비게이션과 전체 화면 패널로 자연스럽게 바꾼다. 기능을 한 화면에 다 펼쳐 복잡하게 만들지 말고, 현재 해야 할 한 가지 행동만 선명하게 보인다.

상단 히어로 배너에는 **매우 아름답고 전문적인 비즈니스 정장의 유럽 여성과 한국 남성이 밝게 웃으며 대등하게 사업 대화를 나누는 고급 실사 이미지**를 넣는다. 현대적인 프리미엄 오피스, 자연광, 신뢰감, 과도한 연출이나 성적 대상화 없음, 특정 실존 인물과 닮지 않음, 21:7 와이드 비율, 인물은 중앙 문구를 가리지 않도록 좌우 배치한다. 정식 라이선스를 확인한 이미지 또는 생성형 이미지의 생성 기록을 보관하고, 모바일 전용 크롭과 WebP/AVIF를 제공한다.

메인 내비게이션은 최대 6개로 제한한다.

1. **오늘**: 현재 퍼즐 완성도, 가장 약한 조각 1개, 오늘의 행동 1~3개, 연속 실천일, 최근 성취
2. **나의 진단**: 단계형 진단, 행동 증거 입력, 강점·약점·균형·위험요인
3. **퍼즐맵**: 12개 조각의 상태, 원인, 연결 관계, 관련 장, 개선 우선순위
4. **실행 플랜**: 90일 목표, 주간 스프린트, 오늘 할 일, 실패 복기, 습관·기회·인맥 기록
5. **전자책**: 실제 책을 펼쳐 읽는 플립북
6. **AI 코치**: 내 데이터와 책의 근거를 활용한 대화·계획·리뷰

보조 기능인 알림, 내보내기, 개인정보, 구독, 로그아웃은 프로필 메뉴 안에 둔다.

## 일반 앱으로 반드시 구현할 기능

생성형 AI가 없어도 아래 기능은 완전하게 작동해야 한다.

### 1. 온보딩과 목표 계약

- 개인/사업자/리더/예비창업자 등 사용 맥락
- 성공의 개인적 정의, 행복에서 부족한 조각, 90일 핵심 목표
- 하루·주간 사용 가능 시간, 건강상 제약, 재무 위험 허용 범위
- 개인정보 및 AI 처리에 대한 분리 동의
- 입력 중 자동 저장, 나중에 계속하기

### 2. 근거 기반 자기점검

12개 퍼즐마다 4~7개의 문항을 두고 총 60~72문항으로 구성한다. 각 문항은 1~5점 빈도 척도와 “최근 30일의 실제 사례” 선택 입력을 함께 받는다. 예:

- “목표를 이번 주에 실행할 수 있는 크기로 나누었다.”
- “실패 후 원인과 다음 시도를 기록했다.”
- “집중 시간과 회복 시간을 의도적으로 배치했다.”
- “소비 목표 외에 생산·수입·고객가치 목표가 있다.”
- “필요할 때 질문하고, 답변을 확인하여 행동으로 옮겼다.”
- “다른 사람의 권리와 건강을 해치지 않는 방식으로 성과를 추구했다.”

점수는 결정론적으로 계산한다. AI가 점수를 바꾸지 못한다.

```text
dimensionScore = 0~100 정규화 점수
confidence = 응답 완성도 + 행동 증거 수 + 최근성
priority = (100 - dimensionScore) × 목표관련도 × 영향도 × 개선가능성
balancePenalty = 과도한 실행/낮은 회복, 높은 영업/낮은 윤리 등 위험 조합
```

점수만 보여주지 말고 강점, 성장조각, 주의조합, 응답근거, 추천행동을 보여준다. 초기 응답을 베이스라인으로 고정하고 30일 단위로 재평가하여 추세를 비교한다. 문항과 가중치에는 버전 번호를 붙여 이전 결과를 재현할 수 있게 한다.

### 3. 90일 성공 퍼즐 플랜

- 90일 결과목표 1개, 과정지표 2~4개, 금지선/건강선
- 4주 단위 마일스톤과 매주 3개의 핵심 행동
- 행동은 15분·30분·60분 버전으로 자동 분해
- 오늘의 최우선 행동, 일정, 완료, 미완료 이유, 다음 재시도
- 실패·거절을 “퍼즐조각 로그”로 기록: 상황/시도/결과/배운 점/다음 실험
- 기회 포착함, 아이디어·메모함, 감사·나눔 기록, 관계 후속 연락
- 달력, 알림, 연속 기록, 중단 후 재시작

### 4. 실용 도구

- 목표를 행동으로 쪼개는 워크시트
- 중요도/긴급도와 목표관련도로 시간을 배분하는 주간 플래너
- 생산형/소비형 목표 분류기
- 단순 현금흐름·저축 목표 계산기: 모든 가정과 단위를 표시하며 투자수익을 보장하지 않음
- 인맥맵: 이름, 관계, 마지막 연락, 제공할 가치, 동의한 후속 연락만 저장
- 고객가치/영업 준비 체크리스트: 문제, 근거, 제안, 가격, 거절 대응, 사후관리
- 리더십 역할·책임·의사결정 기록
- 데이터 JSON/CSV 및 인쇄용 PDF 리포트 내보내기

### 5. 전자책 플립북

- PDF의 각 면 종횡비를 검사한다. 세로형 면은 한 페이지로, 가로형 두 쪽 펼침은 좌·우를 손실 없이 분리하여 논리적 인쇄면을 만든다.
- 데스크톱은 실제 책처럼 좌우 두 면을 펼치고, 클릭·키보드·휠·모서리 드래그로 한 장씩 넘긴다.
- 드래그 거리와 속도에 반응하는 3D page curl, 자연스러운 그림자, 60fps에 가까운 부드러운 전환, 동작 줄이기 설정을 지원한다.
- 모바일은 한 면 보기와 가벼운 슬라이드/플립 효과를 기본값으로 한다.
- 확대, 전체화면, 목차 이동, 페이지 번호 직접 입력, 썸네일, 검색, 책갈피, 마지막 읽은 위치, 관련 퍼즐로 보내기를 제공한다.
- PDF.js 등 검증된 렌더러를 사용하고 앞뒤 면만 미리 렌더링하며 나머지는 지연 로딩한다. 원문을 앱 번들에 공개 URL로 넣지 않는다.
- 접근성용 텍스트 레이어와 키보드 조작을 제공한다.
- 진단 결과의 각 조각에서 관련 장과 인쇄면으로 바로 이동하고, 전자책에서 “이 장 실천하기”를 누르면 행동 카드가 열린다.

## 생성형 AI가 필요한 기능

AI 기능은 서버 측 API 연결이 실제로 성공한 경우에만 활성화한다. 연결되지 않았으면 “AI 연결 안 됨”과 설정 방법을 명확히 표시하고 가짜 분석이나 미리 정한 문장을 AI 결과처럼 보여주지 않는다.

1. **AI 진단 해설**: 결정론적 점수와 사용자의 행동 증거를 바꾸지 않고, 이해하기 쉬운 개인화 해설을 작성
2. **AI 90일 설계 보조**: 사용자가 승인·편집할 수 있는 목표/마일스톤/행동 초안 제안
3. **AI 실패 복기**: 비난 없이 통제 가능 요인, 가설, 다음의 작은 실험 제시
4. **AI 역할 코치**: 영업 대화, 거절 대응, 리더십 대화, 질문 훈련. 기만·압박·차별은 금지
5. **AI 주간 리뷰**: 실제 완료 기록만 사용해 성취, 병목, 다음 주 우선순위를 요약
6. **책 기반 질의응답**: 검색된 원문 조각에만 근거하여 답하고 장 제목과 인쇄면을 표시. 근거가 없으면 모른다고 답함

AI 입력에는 필요한 최소 데이터만 보내고 민감정보는 기본적으로 제외한다. 사용자별 데이터가 다른 사용자에게 섞이지 않게 한다. 시스템 프롬프트는 다음 규칙을 포함한다.

```text
당신은 성공을 보장하거나 사용자를 등급화하는 심판이 아니다.
책의 관점, 사용자의 실제 기록, 앱의 계산 결과를 구분하라.
낮은 점수를 인격이나 능력의 결함으로 해석하지 말라.
과로, 위험투자, 기만적 영업, 맹목적 복종을 권하지 말라.
답변은 관찰 → 근거 → 선택 가능한 작은 행동 → 사용자의 승인 순서로 작성하라.
책에 없는 사실을 저자의 주장처럼 만들지 말라.
인용은 짧게 하고 장 제목과 인쇄면을 표시하라.
```

모든 AI 결과는 `초안`, `사용자 편집`, `승인`, `폐기`, `생성 시각`, `모델`, `근거 장`, `프롬프트 버전`을 저장한다.

## 사용자 리포트

리포트는 첫 화면에서 결론을 먼저 보여준다.

- 나의 현재 성공 퍼즐 한 문장
- 상위 강점 3개와 실제 근거
- 우선 성장조각 3개와 선택 이유
- 위험한 불균형 조합
- 90일 북극성 목표
- 이번 주 행동 3개
- 책에서 다시 읽을 장 3~5개
- AI 해설과 비AI 계산 결과의 명확한 구분
- “이 결과는 현재 응답을 바탕으로 한 자기성찰 도구이며 성공을 보장하거나 임상·재무 진단을 하지 않습니다.”

## 마스터 관리자

상단 우측에 눈에 거슬리지 않는 **마스터 관리자** 버튼을 둔다. 초기 부트스트랩 비밀번호는 사용자가 요청한 `6085`이지만 프런트엔드 코드, HTML, JavaScript 번들, 저장소, 로그에 절대 하드코딩하지 않는다.

- 서버 비밀값 `ADMIN_BOOTSTRAP_PASSWORD=6085`로 최초 1회만 설정
- 최초 로그인 시 강력한 새 비밀번호 변경 강제
- Argon2id 또는 동등한 강도의 해시 저장
- HttpOnly/Secure/SameSite 쿠키 세션, CSRF 방어, 로그인 속도 제한, 실패 잠금, 감사 로그
- 운영환경에서는 2단계 인증 또는 패스키 지원
- 비밀번호 원문은 관리자 화면/API 응답에서 다시 보여주지 않음

관리자 화면은 단순 입구가 아니라 실제 운영 콘솔이어야 한다.

- 사용자/구독/권한/동의/탈퇴/데이터 삭제 요청
- 진단 문항, 퍼즐, 가중치, 문항 버전, 추천행동 CRUD
- 책 장·인쇄면·원문 근거·12개 퍼즐 매핑과 공개 상태 관리
- PDF 업로드, SHA-256, 페이지 분석, 권리 승인, 공개/비공개, 버전 롤백
- 배너와 브랜드 콘텐츠, 공지, 약관, 개인정보처리방침
- AI 제공자, 모델, 서버 측 API 키, 비용 상한, 응답 길이, 연결 테스트, 사용량
- AI 기능별 켜기/끄기, 프롬프트 버전, 실패 로그, 안전 로그
- 결제 플랜/쿠폰/환불 상태(실제 결제사 연결 전에는 테스트로 명시)
- 익명화된 퍼널과 완료율, 오류, 내보내기
- 운영 변경 감사 로그와 이전 버전 복구

API 키는 서버 측에서 암호화해 저장하거나 플랫폼의 Secret 저장소를 사용한다. 저장 후에는 끝 4자리만 표시한다. “연결 테스트”가 실제 제공자 응답을 확인해야 `연결됨`으로 표시한다.

## 기술·데이터 구조

React/TypeScript 기반 반응형 PWA와 서버 API를 사용한다. Cloudflare를 선택한다면 Workers + D1 + R2를 기본으로 하고 PDF 원본/페이지 자산은 비공개 R2에 저장하며 짧은 수명의 권한 확인 스트리밍으로 제공한다. OpenAI 등 생성형 AI API 키는 Worker Secret에 둔다.

최소 데이터 모델:

`users`, `sessions`, `consents`, `assessments`, `assessment_answers`, `dimension_scores`, `goals`, `milestones`, `actions`, `failure_logs`, `opportunity_logs`, `relationship_notes`, `book_versions`, `book_pages`, `book_chapters`, `chapter_dimension_map`, `bookmarks`, `reading_progress`, `ai_settings`, `ai_runs`, `ai_feedback`, `subscriptions`, `admin_audit_logs`.

모든 사용자 데이터는 user_id로 격리한다. 관리자 API는 역할을 다시 확인한다. 데이터 삭제와 내보내기를 실제로 구현한다. 로그에는 비밀번호, API 키, 전체 AI 입력, 개인식별정보를 남기지 않는다.

## 완료 조건과 검증

다음을 모두 통과하기 전에는 “완성”이라고 보고하지 않는다.

1. PDF 전체 페이지 수, SHA-256, 종횡비, 좌우 분리 결과, 첫/중간/마지막 면 육안 검증
2. 목차와 모든 장 제목·인쇄면 매핑 검증
3. 가입 → 온보딩 → 진단 → 결정론적 점수 → 90일 계획 → 행동 기록 → 재평가 → 리포트 흐름
4. 새로고침/재로그인 후 저장 데이터 복원
5. AI 키 없음/오류/한도초과 때 정직한 실패 상태, 실제 연결 때만 AI 결과
6. 일반 사용자가 다른 사용자의 데이터나 관리자 API에 접근할 수 없는지 확인
7. 관리자 비밀번호와 API 키가 클라이언트 번들·네트워크 응답·로그에 노출되지 않는지 확인
8. 책 원본의 비공개 저장과 권리 승인 게이트 확인
9. 플립북 클릭·드래그·키보드·모바일·동작 줄이기 테스트
10. 타입검사, 린트, 단위/통합/E2E 테스트, 프로덕션 빌드, 의존성 보안 점검
11. 360/390/430px 및 데스크톱 브라우저에서 실제 렌더링 QA
12. 배포 URL에서 로그인, API, 정적 자산, 보안 헤더, 개인정보 삭제·내보내기 확인

최종 보고에는 구현된 기능, 일반 기능과 AI 기능의 구분, 데이터 저장 방식, 테스트 결과, 알려진 제한, 권리 승인 상태, AI 연결 상태, 관리자 최초 설정 방법을 사실대로 적는다. 동작하지 않는 기능을 “준비 완료”로 포장하지 않는다.

## 분석자가 정리한 책의 제품화 결론

이 책은 학술적으로 검증된 성공 척도라기보다 저자의 비즈니스 경험과 동기부여 철학을 짧은 글로 반복·강조한 책이다. 앱의 경쟁력은 글을 그대로 퀴즈로 만드는 데 있지 않다. 책의 반복 메시지를 12개 측정 가능한 행동영역으로 바꾸고, 사용자의 실제 최근 행동을 근거로 우선순위를 계산하며, 실패를 다음 실험으로 전환하고, 관련 원문으로 다시 돌아가 읽게 만드는 닫힌 순환에 있다.

가장 적절한 제품 순환은 다음과 같다.

`읽기 → 자기점검 → 강점/성장조각 발견 → 90일 목표 → 오늘의 작은 행동 → 실패·성취 기록 → 주간 복기 → 30일 재평가 → 다시 읽기`

생성형 AI는 이 순환의 설명과 개인화를 돕지만 점수, 기록, 계산, 권한, 결제, 원문 검색의 사실을 대신하지 않는다.
